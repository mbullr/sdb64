SD, the Multivalue String Database

Gui Development Branch, Use With Caution

Sample app (very very rough app) found at:

https://github.com/mbullr/sdPyGui_App

Examples found in /sdb64/sd64/examples/python/embedded_python/BP

sdPyGuiTest.BP - controlling program (must edit location of the script files!)

sdPyGui_setup.py and sdPyGui_step.py - python scripts executed to create and service the gui window

FreeSimpleGUI and Tkinter must be installed.

https://freesimplegui.readthedocs.io/en/latest/

https://docs.pysimplegui.com/

Current example is Tkinter based, but the Qt  (FreeSimpleGUIQt) and WxPython (FreeSimpleGUIWx) branches should work (YMMV).

Have fun!
