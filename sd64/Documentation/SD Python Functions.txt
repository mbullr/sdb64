Python Interface Functions
 PY_CALLFUNCTION
 execute python function
 rtn_stat = PY_CALLFUNCTION(function_name,result_name,arg1,arg2,arg3,arg4,arg5)

 function_name - name of python function previously imported into interpreter (found in __main__ scope)
 result_name - name of exiting python object to receive function results (found in __main__ scope)
 arg1- arg5  - names of python objects previously created in interpreter (found in __main__ scope)
                   status() - 0 on success, error code as defined in ERR.H
                   rtn_stat - same

PY_CALLFUNCTIONS
 execute python function and return results as string
 rtn_str = PY_CALLFUNCTIONS(function_name,arg1,arg2,arg3,arg4,arg5)

 function_name - name of python function previously imported into interpreter (found in __main__ scope)
 arg1- arg5  - names of python objects previously created in interpreter (found in __main__ scope)
                   status() - 0 on success, error code as defined in ERR.H
 rtn_str     - string returned from python function call

PY_GUITABLEGET
 get (read) Gui (FreeSimpleGUI) table list data
 dyn_array = PY_GUITABLEGET(table_list_name)

 table_list_name - object name of existing python list
 dyn_array - dynamic array string containing the table data, example layout:
              row 1 : col 1 data <svm> col 2 data <svm> col 3 data <vm>
              row 2 : col 1 data <svm> col 2 data <svm> col 3 data <vm>
                   status() - 0 on success, error code as defined in ERR.H

PY_GUITABLESET
 populate existing PYGUI FreeSimpleGUI table data from dyn array
 returned_status = PY_GUITABLESET(table_list_name,dyn_array)

 Note PY_GUITABLESET APPENDS the data in dyn_array to list table_list_name.
      If you must clear table_list_name with PY_LISTCLR(table_list_name) before
      calling PY_GUITABLESET if this is not the desired outcome.

 object_name - object name of window created with  "window = sg.Window(....)
 dyn_array - dynamic array string eg):
              row 1 : col 1 data <svm> col 2 data <svm> col 3 data <vm>
              row 2 : col 1 data <svm> col 2 data <svm> col 3 data <vm>
 returned_status - 0 on success, error code as defined in ERR.H
                   status() - 0 on success, error code as defined in ERR.H

                   status() - 0 on success, error code as defined in ERR.H

PY_GUIWINUPDVALUES

  eg) python script example: window["CM_CONTACT"].update(values=CUST_CONTACTS)

 returned_status = PY_GUIWINUPDVALUES(object_name,key,list_name)

 object_name - object name of window created with  "window = sg.Window(....)
 key         - key to Gui Object we want to change
 list_name   - name of python list object to update
 returned_status - 0 on success, error code as defined in ERR.H
                   status() - 0 on success, error code as defined in ERR.H

PY_OBJTYPE
 Return python object type, defined in KEYS.H

 object - name of python object to evaluate
 object_type:
  SD_Obj_Unkn         0  ;* Unknown python object type 
  SD_Obj_Str          1  ;* String (Unicode) python object type 
  SD_Obj_List         2  ;* List python object type 
  SD_Obj_Dict         3  ;* Dictionary  python object type 
  SD_Obj_Long         4  ;* Long (int)  python object type 
  SD_Obj_Float        5  ;* Float (floating point)  python object type 
  
PY_POPUP

 function_name - name of python function which creates the window, defined in preloaded script 
 title_name, message_name - name of exiting python object to receive associated text, then used to populate popup
 title_text, message_text - text to display in popup
 style_name style_setting  - one of (defined in SDPYFUNC.H):
                    PY_PUP_OK      
                    PY_PUP_YESNO   
                    PY_PUP_OKCANCEL
                    
                   status() - 0 on success, error code as defined in ERR.H
                   rtn_stat - same
                   
PY_PYPOLL
 poll to see if the gui scheduled an event to process
 EVENT = PY_PYPOLL()
          EVENT NAME = FIELD(EVENT,@FM, 1)
          EVENT DATA = FIELD(EVENT,@FM, 2)
          status() - 0 on success, error code as defined in ERR.H
          
 use as part of the GUI event processing loop, eg)

    loop while DONE = 0
    
      STATUS.VALUE = PY_PYGUISTEP()
      if STATUS() # 0 then
        crt "PyGUI step failed: ":STATUS()
        DONE = 1
      end else
    *
    *  now poll to see if the gui scheduled an event to process
    *
        EVENT = PY_PYPOLL()
        if STATUS() = 0 then
          EVENT.NAME = FIELD(EVENT,@FM, 1)
          EVENT.DATA = FIELD(EVENT,@FM, 2)

          * evaluate event
          begin case
          
          case EVENT.NAME = "main_window" and EVENT.DATA = "closed" 
            DONE = 1
            exit      ;* get out of loop
          
          case  EVENT.NAME = some event 
            process some event
          .
          .
          .
          case 1 ;* unknown event
            unknow event handler
          end case
            
        end     ;* poll failed, try again?
      end
    repeat
